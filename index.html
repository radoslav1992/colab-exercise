  • 01 Speech to text

    Whisper tiny transcribes a recording, then your own voice from the microphone. The exercise: write the word error rate.

  • 02 Text to speech

    SpeechT5 turns a sentence into sound, in the voice a speaker embedding describes. Play it, and draw its waveform.

  • 04 Attention from scratch

How it works for a teacher

A course, a join code, and assignments that are ordinary notebooks.

  1. Set an assignment from an .ipynb

    Upload a notebook, start from a sample, or begin with an empty one. Add instructions, a due date and points, and publish when it is ready.

  2. Share the join code

    Every course has a code of eight letters and digits. Students create an account and join with it.

  3. Students work in the browser and hand in

    Each student gets a copy that is saved while they type. Submitting stores a snapshot with the server’s time, and marks it late after the due time.

  4. Open, run, grade, release

    One table shows who started and who submitted. Open a submission, run its cells, give a grade and feedback. Students see them when you release them.

Create a teacher account No confirmation email is sent, so you can start at once.

Plain facts

Nothing to install
A notebook opens in a browser tab. Python itself (a build called Pyodide) is downloaded into the tab the first time a cell runs.
The code runs on the student’s computer
The server stores accounts, courses, notebooks, submissions and grades. It never runs anybody’s code.
.ipynb in, .ipynb out
Open a notebook from Jupyter or Colab, and download it again. Cells, tags and outputs survive the round trip.
Models from Hugging Face
They run in the tab, on the graphics card with WebGPU. Without one they fall back to the processor: everything still works, only slower.

And the limits

  • Small models. Tens to a few hundred megabytes, and every student downloads each one once.
  • No PyTorch. Notebooks use NumPy and the course’s small lab package. Pretrained models can be run, not fine-tuned.
  • A recent browser for the graphics card: Chrome or Edge.
  • Checks are a hint. They run in the student’s browser, so the number a submission reports can be faked.
